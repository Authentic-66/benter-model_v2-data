# Phase 3D — Validation Infrastructure

_Generated by `scripts/generate_phase3d_report.py`. No trained model — this phase builds the measurement stack that Phase 3E will use to prove or disprove itself._

## Headline

Phase 3D delivers a **model-agnostic evaluation stack** — cross-validation splitters, metrics, baselines, grid search, and slice diagnostics — all validated against the 116,311-entry GP corpus. No trained model here; that's Phase 3E.

**The two baselines below define the floor and the bar the Benter model must beat:**
- `random_uniform` — trivial 1/field probability. If a model loses to this on log-loss, it's broken.
- `market_favorite` — implied probability from tote odds. If a model loses to this on log-loss, it's not learning anything the crowd doesn't already know. Beating this is the whole point.

## ROI at edge thresholds (market_favorite baseline)

### `hyperparameter_search.py`

```python
from hyperparameter_search import GridSearch
def fit_predict(train_df, val_df, params):
    model = MyModel(l2=params['l2']).fit(train_df)
    return model.predict(val_df)

report = GridSearch(fit_predict,
                    param_grid={'l2': [0.01, 0.1, 1.0]},
                    splitter=RollingOriginSplitter.default_gp_folds(),
                    scoring='log_loss_per_race',
                    minimize=True).run(features_df)
print(report.best_params, report.best_score)
```

## Metric cheat sheet

| Metric | Lower or Higher is better? | Sane range | Notes |
|---|---|---|---|
| `log_loss_per_race` | lower | ~1.5-2.1 for uniform, better ≈ 1.5-1.6 | `-log(P(winner))` per race. `log(field_size)` is the floor. |
| `brier_score_per_race` | lower | 0.7-0.9 baseline | Sum-of-squared-error per race. |
| `ece_10bin` | lower | < 0.02 = well-calibrated | Weighted \|avg_pred - avg_hit\| across 10 buckets. |
| `hit_rate_top1` | higher | 12-13% random, 36% favorite | Fraction of races where the winner is the model's top pick. |
| `hit_rate_top3` | higher | 40% random, 73% favorite | Winner in top-3 picks. |
| `favorite_hit_rate` | reference only | ~35-37% for GP | Empirical win rate of the tote favorite — sanity check. |
| `roi_edgeXX` | higher | negative for weak models | ROI per $1 staked at edge XX% threshold. Above zero = beating the market after takeout. |
| `kelly_pnl_pct` | higher | wildly variable | Fractional-Kelly bankroll growth. |

## What Phase 3D deliberately DOES NOT do

- **Train a model.** That's Phase 3E's job. This phase's framework is model-agnostic; the same evaluation code will score the Benter model, a random forest, or a neural net.
- **Assume old-model predictions.** `BaselineOldModel` is a stub — Doug will export the previous PP-based model's predictions to a CSV when ready. Until then, its `predict` returns NaN and the evaluation layer reports 'not available' rather than crashing.
- **Overfit hyperparameters to the holdout.** Any final test set carved out with `TemporalHoldout` is meant to be touched exactly once, at ship time. The four rolling-origin folds are for tuning; save 2026-Q3 (or later) for the final publish.
- **Build ML-odds or public-lines baseline.** Result PDFs don't carry morning-line odds; that data lands with the Brisnet PP integration in Phase 3G, at which point a `BaselineMorningLine` can be added trivially.
